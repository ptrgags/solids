# Tile Holder (2026-07)

This simple design sets up a base for placing 16 4x4 LEGO tiles so I have a
place to display mosaics that can be easily swapped.

To keep things simple, the plates fit into rectangular slots and are not
connected via studs. This idea was inspired by [LEGO minifig Hexagons](https://www.printables.com/model/93303-lego-minifig-hexagons-extended-edition)
by `Cascadebricks.com` on Printables.
